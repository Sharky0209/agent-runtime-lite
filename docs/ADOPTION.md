# Real-world adoption and feedback

This page tracks ways to evaluate whether Agent Runtime Lite helps independent developers. It is not a marketing scoreboard.

## Evidence to distinguish

- **Working packaged install:** verified locally and on public CI.
- **Independent interest:** external feedback through issues and discussions.
- **Actual adoption:** an external maintainer voluntarily reports using it in a real project, with permission to link the implementation or description.
- **Ongoing use:** recurring integration evidence, fixes based on field reports, or repeat engagement.

GitHub Stars, page views and forks do not by themselves establish real product usage.

## Try it and leave feedback

1. Install the verified [GitHub Release tarball](https://github.com/Sharky0209/agent-runtime-lite/releases/tag/v0.1.2) from the README, or run the [five-minute quickstart](QUICKSTART.md) with a local checkout.
2. Join the public [first independent tester feedback thread](https://github.com/Sharky0209/agent-runtime-lite/issues/3), or open a [bug report](https://github.com/Sharky0209/agent-runtime-lite/issues/new/choose) for any reproducible behavior.
3. For suggestions or integration questions, open a [feature request](https://github.com/Sharky0209/agent-runtime-lite/issues/new/choose).
4. If you have actually used it, an issue describing which workflow benefited, operating system, and anything missing is appreciated. Do not post private logs, company details, secrets, or client information.

## Public adoption records

No third-party project integration is claimed here until the user confirms it and grants permission to cite it. Maintainer-created demo runs are useful integration checks, but are **not independent users**.

The initial adoption checkpoint is 2026-11-25. That is a review date, not a promise of traction or eligibility for any program.
